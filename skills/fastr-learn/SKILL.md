# FastrMemory Autonomous Learning & Synthesis

## Overview
Analyzes recurring development patterns, correlates error traps with successful bug fixes, and consolidates fragmented staging observations into high-level verified architectural rules.

## When to Invoke
- After multiple related bugs or features have been resolved.
- During periodic project memory consolidation.
- When preparing documentation or style guides derived from empirical agent experience.

## Workflow
1. **Analyze Recurrent Traps & Fixes**:
   Examine active traps in `fastr_trap_recall` to find recurring root causes.
2. **Synthesize Permanent Convention**:
   If an error occurred 3+ times across different files, elevate it from a per-file trap into an architectural convention via `fastr_remember`.
3. **Consolidate Memory Graph**:
   Link related memories using `fastr_remember` with associated tags and categories so that subsequent triple-stream RRF retrieval finds the full context in a single call.
